# Trevixa Media — Agency Portfolio

**Turning Vision Into Visibility.**

Interactive client portfolio for **Trevixa Media**, showcasing short-form reels, studio culinary photography, brand & social creatives, venue ambience films, sports action highlights, campus events, and behind-the-scenes production.

## Project Structure

- `index.html`, `styles.css`, `app.js` — Portfolio frontend (filterable 35-item archive, hero reel switcher, L'Unico Cafe spotlight, cinema lightbox, and interactive project brief builder)
- `server.js` — Zero-dependency Node.js static server with HTTP `Range` support for smooth `.mp4` video seeking
- `media/` — Web-ready portfolio assets (`logo/`, `designs/`, `food/`, `thumbs/`, `videos/`)

## Run Locally

```bash
npm start
```

Then open [http://localhost:4173](http://localhost:4173).
